El chi-cuadrado compara cuántos valores cayeron en cada intervalo contra cuántos se esperaban si la distribución fuera uniforme. Si el valor calculado es menor o igual al valor de tabla, no se rechaza la hipótesis de uniformidad. Si es mayor, se rechaza.

Con N pequeño, esta prueba debe interpretarse de forma educativa. Para una evaluación más representativa conviene usar más iteraciones, por ejemplo 1000.
